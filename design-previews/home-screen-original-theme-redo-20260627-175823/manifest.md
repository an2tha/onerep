# Redo — original theme, actually different structures

User rejected prior set because it reused the same card/list scaffold. This redo keeps the OneRep theme but changes IA and structure per option.

Shared visual constraints: warm app background, ink text, muted borders, rounded native surfaces, old greeting header, no new color worlds.

Distinct structures:
1. Calorie Dial — radial daily instrument, no list-first layout.
2. Day Timeline — vertical chronological rail as the spine.
3. Meal Focus — bottom-sheet-like next meal workspace.
4. Split Ledger — two-column balance sheet with macro/water/training accounts.
5. Bare Control — ultra-minimal command surface with large tappable rows.
